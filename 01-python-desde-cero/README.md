# Taller 1. De Excel, SAS o R a desarrollo en Python

Material del primer taller de la ruta. Está pensado para analistas estadísticos que vienen de SAS, R o Excel avanzado y necesitan empezar a programar en Python con buenas prácticas desde el primer día: entorno virtual, scripts con funciones, control de versiones y un uso crítico de los asistentes de IA.

## Qué vas a aprender

| Módulo | Tema | Resultado al finalizar |
|--------|------|------------------------|
| 0 | Antes de empezar | Python y VSCode instalados y verificados |
| 1 | Tu primer proyecto en Python | Un script `.py` corriendo desde la terminal |
| 2 | De Jupyter a `.py` | Un notebook migrado a un script reutilizable |
| 3 | Git y GitHub | Tu código versionado y publicado en un repositorio propio |
| 4 | Asistentes de IA en el IDE | Una función nueva implementada con apoyo de IA, entendida antes de aceptarla |

## Qué hay en esta carpeta

- `guia/` es la guía completa, un archivo por módulo. Se lee en orden y cada módulo termina con un ejercicio práctico, una tabla de troubleshooting y recursos para profundizar.
- `material/modulo_1` a `material/modulo_4` son los archivos de referencia que la guía te pide escribir. Sirven para comparar cuando algo no funciona, no para copiar y pegar de una vez.

## Cómo usarlo

Empieza por `guia/01-introduccion.md` y sigue el orden de los archivos. La guía asume Windows con PowerShell, aunque anota las diferencias para macOS y Linux donde aplican.

Si recibiste este taller como zip, adentro viene también la guía en formato Word con el mismo contenido.

## Requisitos previos

Ninguno de programación. Se aprovecha tu base estadística: en cada concepto nuevo hay un paralelo con SAS y R para que ancle más rápido.
